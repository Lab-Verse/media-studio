# Risks

| Risk | Practical control | Owner |
| --- | --- | --- |
| Script or shot changes invalidate expensive renders | Lock script, reference pack and coverage. Rerun affected takes only. | Director and producer |
| Spark memory contention or disconnect | Check shared memory and queue, obtain existing reservation, save job ID, reconcile remotely on reconnect, verify service recovery. | Spark operator |
| Character and dialogue drift | Reference IDs and continuity sheets, dialogue-first edit, human review with motion and cut adjacency visible. | Director and sound |
| Urdu pronunciation or subtitles fail | Native human listening, pronunciation sheet, manual RTL and caption timing review. | Sound and QC |
| Model or asset restrictions | Check checkpoint, music, footage, voice and likeness rights for each channel, territory and intended use. | Rights reviewer |
| Third-party node or dependency breaks production | Review upstream, pin revisions, test in isolation, keep baseline untouched. | Spark operator |
| Repetitive or reused content harms channel eligibility | Original episode value, meaningful derivatives, separate rights and platform review. | Channel producer |
| Model tests are mistaken for production capacity | Track render time per approved second, retries, editor time and failure recovery before scheduling. | Producer |
