name: studio-production
description: Coordinate a Codex media crew from brief through script, picture, sound, private delivery and platform release. Use for originals, social videos, podcasts, drama pilots, episodes and seasons.
---

- Read the project state and the production brief. Choose the output mode and language, creative constraints, source rights and target review. Use the role contracts in docs/CREW-AND-SKILLS.md.
- For an open creative brief, delegate to studio_creative_lead with $studio-creative-development before script lock. Record the concept, strongest opening, look and sound treatment and the smallest proof needed. When direction is already in the approved brief, delegate targeted improvements.
- Assign artifact owners before any concurrent work. Wait for beat and script decisions before locking coverage. Have picture, sound and rights reviewers inspect their own evidence.
- For generative drama, lock reference images, approved line recordings and an animatic before commissioning full-resolution shots. For clips, retain source timecodes and context and prove the selected speakers are visible and audible.
- Advance via docs/IMPLEMENTATION-PLAN.md. Record artifact revision, authority and decision at each gate. Use docs/ARTIFACTS.md for handoffs and the relevant specialist skill for execution.
- If the task is planning-only, return the plan and explicit acceptance evidence still needed. Treat private exports, uploads, schedules and releases as distinct user actions.
