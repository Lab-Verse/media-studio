# Media Studio project

Build a reusable Codex crew and production workflow for spoken audio, social video, YouTube originals, dramas and seasons using the existing Spark media stack. A Creative Lead explores original concepts and tests the riskiest idea before script and production design. Start with one original production and scale from measured throughput and quality.

The first proposed pilot is a 60–90 second Urdu micro-drama and one separately reframed vertical cut. A smaller fictional example tests the planning handoffs. The first audio-only deliverable can be the same scene as a short audio drama with the voice track and sound design mixed for listening.

Success includes an approved script and coverage plan, recoverable versioned takes, a private review master with editable dialogue/music/effects stems, verified captions, and usable production evidence. A separate release decision applies to public distribution.
