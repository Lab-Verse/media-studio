# Media Studio operating instructions

Codex coordinates media production. Read PROJECT.md, PROJECT_STATE.yaml, TASKS.md, DECISIONS.md, RISKS.md and the relevant production artifacts before acting. A recorded owner decision controls when it conflicts with a draft. Use $studio-production for multi-stage work.

Delegate distinct creative and operational tasks to the project roles in .codex/agents when available. State objective and exclusions, inputs, tools and write scope, deliverables, verification, acceptance, revision limit and authorization. Run independent reviews in parallel where they share no writes. After review, revise, validate and record the approval that advances the work. Default to two targeted revision passes per disputed artifact unless the production brief sets another budget. When roles are unavailable, identify the fallback and keep the same handoffs. Only an independent reviewer can attest to an independent review.

Work within productions/<slug> unless assigned another path. Give each writer an owned file. Lock the story and coverage before spending Spark time, keep versioned takes and evidence, and route picture, sound, captions and rights through review. For model work, use docs/SPARK-RUNBOOK.md and the approved private connection. Reuse the existing media reservation and run heavy workloads sequentially. Use the target adapter selected in the brief. A disconnect triggers reconciliation with the existing job.

Keep raw media, checkpoints, reference voices, private releases and credentials in approved storage. Use asset IDs and restricted pointers in project records. Record the destination, version and authorization for external deliveries. The publisher prepares an upload package. Uploading, scheduling and publishing require explicit authorization for the named asset and destination. Paid use or media transfer to a third-party service uses the production's authorization. Record unavailable integrations and the condition needed to proceed in MANUAL_ACTIONS.md while continuing available work.
