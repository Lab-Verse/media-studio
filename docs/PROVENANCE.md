# Source provenance and publication scope

Snapshot assembled 25 November 2026 from the existing Media Studio starter and documentary production workspace. The original workspaces were read without changing the production engine, Spark services, files or jobs.

The Media Studio source commit was `97b4f08`. The documentary workspace was not a Git repository, so the [source manifest](SOURCE-MANIFEST.json) records per-file source and published hashes. Source paths are relative logical paths; private workstation identities and Git history are excluded. Final published hashes include the documented portability/security changes.

Included: 13 original crew instructions, nine skill definitions, reusable planning documents, fictional examples, gate templates, the source validator, documentary modules and selected adapters/tests, and the nine-document Drive plan.

Excluded: original `.git`, production histories and receipts, host-specific smoke service-control code, personal connection details, episode manifests/media/deliveries, voice references, models, caches, temporary episode scripts, the host-bound transfer helper/test, and supplied third-party graph JSON whose redistribution rights were not established. The complete production workflow is documented even where a site-specific implementation is intentionally absent.

Added for this repository: public README/state/tasks, workflow map, setup and security notes, source/publication validation, CI, a synthetic smoke manifest and an empty credential template. The Shorts supplied-score path is confined to its project and covered by regression tests. One caption override test now uses a self-contained fixture instead of an excluded private episode manifest. No live rendering, account setup or autonomous service enablement is part of the repository publication.
