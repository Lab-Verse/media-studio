# Security boundaries

Use this source snapshot with operator-reviewed inputs. It is not a sandbox for untrusted packages. Do not run a supplied script, install a supplied node, accept an arbitrary media URL, or grant a submitted manifest authority over credentials, channel identity or publishing policy.

Keep ComfyUI and model endpoints on private, operator-approved interfaces. Rendering and model downloads consume resources and require your own authorization. Never interrupt another production or stop a shared model service from an example command.

The public snapshot confines the Shorts supplied-score path to its selected project and rejects absolute paths, traversal and symlink escapes. That check does not establish complete hostile-input isolation for the renderer. The proposed Drive adapter must enforce its archive, source, rights, size, identity and duplicate contracts before admitting a production.

The safe validation commands in README inspect local source or use temporary fixtures. They do not establish GPU, provider, dependency-vulnerability, editorial or unattended-operation acceptance.

For a suspected vulnerability, contact Labverse privately through https://labverse.org/contact. Do not include secrets or private media in a public issue.
